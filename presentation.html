Application & Functionality

Portraitron captures your likeness and translates it into physical art using precision robotics.

1. Capture Subject standing in a specific spot, photographed in high definition.
2. Conversion Images processed into drawing strokes via algorithmic mapping.
3. Execution Robotic arm (UR5e) performs the drawing on paper.

Project Scope

In-Scope

  • High-definition subject photo capture.
  • Stroke generation using SwiftSketch or similar.
  • UR5e trajectory planning and execution.
  • Automated pen/stamp pickup and placement.
  • Physical hand-off of the completed portrait.

Technologies

Hardware UR5e Robotic Arm, 2D Cameras, Custom 3D-Printed Pen Holders.
Software ROS (Robot Operating System), Python, OpenCV.
Algorithms SwiftSketch for stroke generation, MoveIt! for path planning.

Work Plan

Weeks 1-4 Setup, research, and basic UR5e trajectory testing.
Weeks 5-8 Vision system integration and stroke algorithm refinement.
Week 9 Milestone: Proof of Concept (POC)
Weeks 10-12 Integration, testing, and final demonstration.

Responsibility Matrix

Vision & Image Processing Capture, background removal, stroke conversion.
Robot Control Kinematics, path planning, ROS communication.
Systems Integration Mechanical design, workflow logic, testing.

Proof of Concept (Week 9)

Objective: Draw a precise circular line on paper.

  • Feasibility: Validates coordinate mapping from vision to robot space.
  • Mechanical: Tests stability of the custom pen end-effector.
  • Confidence: Identifies potential pivot points before final integration.
